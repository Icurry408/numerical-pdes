\noindent
For the \(2\)-norm, the error is dominated by the first-order endpoint errors, since the interior points are approximated with a second-order method. The error-vector norm therefore scales like \(O(h)\), while the norm of the exact derivative grows like \(\sqrt{N}=O(h^{-1/2})\). Thus, the relative \(2\)-norm error scales like \(O(h^{3/2})=O(N^{-3/2})\). The infinity norm is dominated by the first-order endpoint errors and therefore scales like \(O(N^{-1})\). These rates are confirmed in Figure 2b, where the reference slopes closely match the observed convergence rates.

\noindent\textbf{3)} Our next problem considers a given ODE where we want to establish Dirichlet boundary conditions and a forcing function. Our method of manufactured solutions allows us to choose a solution and then determine the forcing function and boundary conditions that will produce the solution. We have chosen the solution \(u(x) = \sin(x)\) and set the corresponding boundary conditions and forcing function to test the solution. 
The centered second-order approximations produce a tridiagonal linear system because each interior equation couples only neighboring grid values. The Dirichlet data are known, so their contributions were moved to the right-hand side before solving. The system was solved for interior points and then reconstructed.
Our numerical solution is compared with the exact solution in Figure~\ref{fig:p3_solution}. The relative error convergence is shown in Figure~\ref{fig:p3_convergence}, where we can see that the error converges at a rate of \(O(N^{-2})\) for both norms.

\noindent
With Neumann conditions imposed on all four boundaries, the resulting linear system is singular. 
In the discrete system, the constant vector lies in the nullspace of the finite-difference Laplacian, 
so the solution is only determined up to an additive constant. The same issue occurs in the PDE: 
the Neumann data prescribe derivatives of \(u\), not its absolute level, so \(u+C\) satisfies the 
same boundary conditions. A unique numerical solution can be obtained by adding one normalization 
condition, such as fixing \(u(0,0)=0\) or prescribing the mean value of \(u\).
